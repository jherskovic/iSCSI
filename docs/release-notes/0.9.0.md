**New**

- Faster random reads. The cache now reads only as much around each request as the workload calls for, instead of always 256 KB.
- Volumes are mounted noatime, so reading a file no longer writes to the disk.
- Targets are grouped by protocol, and each protocol remembers its last portal.
- On macOS 27, an experimental attach engine with concurrent reads, off by default (#4).

**Fixes**

- Detach no longer forces a volume that is in use. You're asked first, and Cancel is the default. Removing a target, uninstalling and updating stop instead.
- A disk can be attached in only one account at a time, and an attached target's address, name and LUN can't be edited.
- A target that accepts the connection but never answers now times out instead of hanging.
- macOS 26: turning on the extension no longer disconnects volumes mounted in other accounts.
- Failures to save or delete a CHAP password are now reported.
- Uninstall finishes cleaning up, and moves the app to the Trash.

**Upgrading**

- After the update, Setup asks you to **Reinstall** the background service. On macOS 26, click **Enable** again as well.
