**Fixes**

- Targets that redirect logins now connect. Dell EqualLogic arrays send every login on the group address to a member port; the app used to stop with "The target redirected to …". It now follows the redirect, over the same network interface when the target is pinned to one.
- When a target refuses this Mac (status 0x02/0x02), the message now names the initiator IQN that was sent and whether CHAP was used, and points at the target's access list instead of the target name.
- Errors from the app's own checks, such as a CHAP user with no saved secret, now say how to fix them.
- Status 0x02/0x01 now reads as an authentication failure, so it no longer looks like 0x02/0x02.
- Discover no longer drops CHAP credentials for a target you have already saved. If the saved target has no CHAP user, or a different one, Discover offers **Use These Credentials** instead of showing it as added.

**Command line**

- `iscsictl verify`, `wipe`, `read-bench` and `write-bench` follow login redirects.
- `iscsi-target-sim --redirect-to <address>` acts as a redirecting group address.

**Upgrading**

- After the update, Setup asks you to **Reinstall** the background service. On macOS 26, click **Enable** again as well.
