**New**

- **The app is now called iSCSI/NVMe/TCP Initiator** in the menu bar, the Dock and Finder.
- **`iscsictl` comes with the app.** Setup offers to link it at `/usr/local/bin/iscsictl`, which asks for an administrator password. The link is optional, and Uninstall removes it. Commands are grouped by protocol: `iscsictl iscsi …` and `iscsictl nvme …`. The commands that write to a target directly are not included.
- **NVMe namespaces from the command line.** `iscsictl nvme add`, `attach`, `detach` and `remove` save a namespace, attach it as a `/dev/diskN` device, detach it and remove it again, so scripts can do what the app does. Run them as yourself, not with `sudo`. [docs/iscsictl-nvme.md](https://github.com/jherskovic/iSCSI/blob/main/docs/iscsictl-nvme.md) has the details.
- `iscsictl nvme discover` and `verify` take `--log-level` for a timestamped trace.

**Fixes**

- **Accounts on a shared Mac no longer share targets.** Saved targets and CHAP passwords now belong to the account that uses them. Before, any account could see, attach, edit or delete every target, and use its saved password.
- Uninstall removes only your own targets and passwords, and tells you about any other account's that it kept.

**Upgrading**

- After the update, Setup asks you to **Reinstall** the background service. On macOS 26, click **Enable** again as well.
- The first account to open the app after the update keeps the existing targets and their passwords. Other accounts start empty and need to add their targets again. If another account has a volume attached, detach it before updating.
- If the app is in your Dock, it keeps its old name there until you remove it from the Dock and add it back.
