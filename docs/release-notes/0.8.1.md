**Fixes**

- **Synology targets.** A Synology NAS maps its first LUN at 1. With the default LUN 0, the app attached a 32 KB placeholder disk and offered to format it (#3). The app now checks the target's LUN list before attaching and refuses a LUN that isn't on it, naming the ones that are. The real LUN was never written to.
- **Find** button next to the LUN field. Asks the target which LUNs (or NVMe namespaces) it has and how big they are, and fills in the number when there's only one.

**Upgrading**

- After the update, Setup asks you to **Reinstall** the background service. On macOS 26, click **Enable** again as well.
